# IAYO 🧠

IA experimental propia de Sbtias.

## Componentes
- **IAYO local**: modelo LLM ejecutado en el navegador mediante WebGPU/WebLLM.
- **Memoria persistente**: Supabase.
- **Conversaciones**: Supabase guarda mensajes y sesiones.
- **Núcleo experimental**: red neuronal visual entrenable.
- **GitHub**: código fuente y evolución del proyecto.

> Prototipo. Las tablas públicas usan RLS, pero todavía no existe autenticación por usuario. Para producción conviene añadir Supabase Auth y políticas por usuario.
